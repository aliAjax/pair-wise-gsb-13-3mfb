# 加油站储值账户结算台

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Pinia、Element Plus
- 启动：`npm install && npm run dev`
- 构建：`npm run build`

## 账务规则（全部在前端落盘，localStorage key：`fuel-stored-value-v1`）

1. **整笔订单扣款**：加油订单按整笔金额一次性从储值余额扣除；余额不足时禁止保存，必须改用现金或电子支付。
2. **退款约束**：只能引用「已结算」订单，单笔及累计退款不得超过原订单实付金额。
3. **交班冻结**：交班后对全部储值余额拍快照冻结，冻结班订单与余额不可修改。
4. **更正留痕**：冻结班次的任何更正都只能新增带原因、经办人、旧值、新值的冲正记录，旧值保留。
5. **跨班退款**：退款发生在当前班、订单属于已冻结原班时，储值退款先补回客户余额（原班快照不动），现金/电子支付从当前班退付，并自动生成关联原班的冲正记录。
6. **刷新一致**：余额 = 该客户全部流水（充值 − 加油扣款 + 退款补回）之和，随时可由流水重算。

金额内部一律以「分」整数存储。演示数据含一个已冻结早班和一个进行中中班，可直接演练跨班退款；右上角可一键重置。
