# 加油站储值账户结算台

- 行业：石油
- 技术栈：Vue3、Vite、TypeScript、Pinia、Element Plus
- 启动：`npm install` 后执行 `npm run dev`
- 构建：`npm run build`

## 业务规则

1. **整笔订单结算**：每次加油生成一笔订单，只能选择一种支付方式（储值 / 现金 / 电子支付）。
2. **储值余额校验**：选择储值扣款时按整笔金额校验余额，余额不足不能保存，页面强制改用现金或电子支付。
3. **退款约束**：退款只能引用已结算订单，金额不得超过“原订单实付 − 已退金额”；退款原因必填。
4. **交班冻结**：交班后班次内订单与储值余额冻结，不允许删除或覆盖；更正只能新增带原因的冲正记录，记录中保留原单实付、冲正前销售/已冲正、冲正后净额、客户操作前余额等旧值。
5. **跨班退款**：原班已冻结时，先在原班追加冲正记录并补回储值余额（流水挂原班），退款支出再计入当前班次。
6. **退款台账**：列出客户、原订单、退款额、退款后余额、受理班次与冲正号。
7. **落盘与一致性**：所有变更原子写入 localStorage；客户余额由储值流水（充值/扣款/退款补回）实时推导，订单已退金额由退款单推导，刷新页面后自动执行账务自检。

## 数据模型

- 客户 Customer（余额非存储字段，由 ledger 推导）
- 班次 Shift（开班 / 交班时间、备用金）
- 订单 Order（整笔实付、支付方式、储值支付后余额快照）
- 退款 Refund（引用订单、金额、原因、是否跨班、冲正号）
- 冲正 Correction（冻结班次唯一允许追加的记录，保留旧值）
- 储值流水 LedgerEntry（topup 充值 / sale 扣款 / refund_credit 退款补回）
